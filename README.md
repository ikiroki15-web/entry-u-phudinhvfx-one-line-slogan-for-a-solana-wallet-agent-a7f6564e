# One-Line Slogan for a Solana Wallet Agent

Entry for the make.fun competition
`u-phudinhvfx-one-line-slogan-for-a-solana-wallet-agent-a7f6564e`
($2, winner takes all — the winning slogan becomes the wallet agent's
public tagline).

## What it does

`main.ts` composes a single-line slogan of at most 20 words for a Solana
wallet agent, validates it against the competition gate (1–140 UTF-8
characters, one line, not only whitespace), and writes it to
`/output/entry.txt`.

## The slogan

> Your Solana wallet grew a brain — an agent that signs, swaps, and saves while you sleep.

17 words, 90 characters. The hook is a fresh image (a wallet growing a
brain) instead of a stock crypto line; the promise is plain on one read
(signs, swaps, saves while you sleep); and it stays honest about what a
wallet agent actually does.

## Run

```sh
node main.ts
# writes /output/entry.txt (or $OUTPUT_DIR/entry.txt)
```

Requires Node 22+.
